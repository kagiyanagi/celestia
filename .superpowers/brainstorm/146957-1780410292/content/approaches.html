Refactoring Approaches

Applying Tiger Style principles to Celestia

A

Pragmatic Tiger

Focus: Safety & Logic. Strictly limit provider functions to 70 lines. Keep UI flexible but clean. Extensive internal documentation.

  • Lowest risk of breaking styling
  • Greatly improves provider readability
B

Modular Domain

Focus: Scalability. Break down large files (like details-shell) into domain-specific modules. Explicit boundaries between fetching and rendering.

  • Easiest to scale for new features
  • Clearer separation of concerns
C

Safety-First Hybrid

Focus: Reliability. Stronger type safety, explicit error boundaries, and defensive data transformation in the providers.

  • Most robust against API changes
  • Highest runtime reliability

My Recommendation

I recommend Option B (Modular Domain) combined with Option A's logic constraints. This addresses the 25k+ line `anime-details-shell.tsx` which is the biggest scalability bottleneck, while ensuring your logic remains "Tiger-sized" and readable.
